# Using Collated

Collated turns a stack of scanned pages or phone photos into one PDF. You add the images (or whole PDFs), put them in order, straighten or crop any page that needs it, choose a paper size, and export. It all happens in your browser: nothing is uploaded.

- [Exporting](guide/exporting.md): quality, file size, searchable text, page numbers, watermarks, passwords.
