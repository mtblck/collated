# Troubleshooting

**A file wasn't added.** A message names it and says why: not an image or PDF Collated can read, a PDF that needs a password to open, an image over 100 megapixels, or a PDF over 500 pages.

**A page prints soft.** The panel shows **Prints at** in dpi; under about 150 dpi it warns that it may look soft. Use a higher-resolution scan, or a smaller page size.

**The file is too big.** In the **Export** options, choose **Balanced** or **Small**, or set **Keep the file under**. B&W pages are compact for text.

**Auto-straighten did nothing.** It needs lines of text to measure. For photos or drawings, use the **Straighten** slider.

**A photo is sideways.** Use **Rotate**. If a whole batch came in sideways, **Rotate all pages** is in the toolbar's **More** menu.

**Searchable text is missing or wrong.** It recognises English only, works best on clear, straight, high-resolution scans, and skips pages that came from PDFs (those usually have their own text already). Try **Crop to the page** and **Straighten** first.

**Something else.** [Report a problem](https://github.com/mtblck/collated/issues). Please don't attach private documents.
